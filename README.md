# 便宜 VPS：年付 $36.9 起的 DMIT 套餐价格表、优惠码和选机思路

搜「便宜 VPS」的人，需求其实一点都不模糊：月付几十块以内，机器能长期开着，国内访问别慢到没法用。难的是给这个需求找答案——各家低价套餐的参数表长得几乎一样，真正拉开差距的东西（超售程度、回程线路、续费价、超量之后怎么处理）往往不写在参数表里。

这篇把 DMIT 这条产品线摊开说：Tier 1 年付 $36.9 起具体是哪一档，洛杉矶 CN2 GIA 从 $9.99/月开始是什么配置，香港和东京贵在哪，优惠码现在还有哪些能试。看完你应该能判断自己该花多少钱，而不是被"低至 X 美元"这句广告词带着走。

## 便宜 VPS 的"便宜"，其实是三笔账

同样标着 $9.9/月，两台机器的实际成本可能差一倍。区别在这三处：

**首年价和续费价。** 有些商家的低价只给第一年，第二年按原价续，算下来总成本反而更高。DMIT 的常规套餐是循环计价，标多少续多少，促销码如果是 recurring 类型，续费也会带着折扣。这一点在下单前值得在结算页确认一遍。

**标称配置和能跑满的配置。** 1 核 1G 是配置，能不能在晚高峰连续跑满 CPU 是另一回事。低价 VPS 最常见的做法是超售，参数不变但邻居多了。

**流量额度用完之后的处理方式。** 这是最容易被忽略的一条，也是 DMIT 区别于多数同价位商家的地方：Tier 1 系列流量跑完之后不停机、不额外计费，只把带宽降到 50Mbps–1Gbps 继续用（具体限速值看档位）。

## 低价套餐最容易踩的三个坑

第一个坑是线路名和实际回程对不上。宣传页写"优化线路"，你可能只被优化了去程，回程走的是普通国际带宽，晚高峰直接趴窝。

第二个坑是库存。便宜套餐经常是限量补货，卖完就下架，等你纠结两天再回来看，商品页已经空了。DMIT 这两年的低价档位就反复出现过补货又售罄的情况。

第三个坑是"便宜"和"稳定"被混为一谈。年付十几美元的机器跑个人博客、监控、反代完全够，但拿去做正经生产业务，磁盘性能和服务等级跟成熟平台就是有差距。DMIT 在部分新批次套餐的页面上会直接标注平台仍在优化阶段，提示磁盘性能与 SLA 可能低于成熟平台——这种提示反而是好事，至少它说了。

## DMIT 便宜的那一档，到底卖什么

DMIT 主要做美国洛杉矶、香港、东京三个机房，按网络质量拆成三条线：

- **Tier 1（T1）**：国际线路，不做中国大陆方向优化，价格最低，年付 $36.9 起

如果你预算卡得很死，真正能落地的就是 T1 系列。它的定位很干脆：不保证国内延迟好看，但保证流量超了不断网、价格常年不涨。

网络结构上，DMIT 有自己的骨干和 ASN，路由追踪里能看到 AS906 和 DMIT-BB 的标识，这跟纯转售上游资源的小商家不是一回事。

顺手提一句，香港、东京、洛杉矶三个机房之间已经支持内网互通，跨机房传数据不用绕公网，做多机房部署的话省事。

## 优惠码：DMIT 不是靠码便宜的商家

DMIT 发优惠码的频率不高，力度也不夸张，更多时候是直接给某款套餐定一个促销价（比如 T1.WEE 的 $36.9/年，页面显示多少就是多少，不需要填码）。

目前比较稳定、被反复引用的是 Standard（原 Lite）系列的两个循环码：

- `Lite-Annually-Recur-30OFF`：年付 7 折，循环生效
- `Lite-Semi-Annually-Recur-20OFF`：半年付 8 折，循环生效

网络上还能搜到一堆名字很长的活动码（涉及洛杉矶 Pro/EB、香港东京 Pro/T1 的季付折扣等）。这类码大多是限时活动的产物，能不能用完全取决于活动是否还在。做法很简单：结算页选好套餐和周期，把码填进去点验证，能用就用，不能用就换一档更好的付款周期，别为了凑一个不确定的码改变自己的购买计划。

## 月付还是年付

年付的门槛低到有点反常识：T1.WEE 一年 $36.9，折合每月 3 美元出头，比同系列月付的 $6.9 便宜一半还多。但年付压的是现金流，也是判断力。

一个务实的做法是：如果你的用途是个人博客、反代、监控、学习环境这类**跑挂了也不心疼**的场景，直接年付最低档，成本最低。如果是要迁移现有站点、跑数据库或者面向客户的业务，先用月付（或者季付）跑一两个计费周期，看过晚高峰延迟、丢包和磁盘 IO 之后再决定要不要年付。

洛杉矶 Pro/EB 的 TINY 档月付不到 10 美元，作为"试用一下优化线路到底怎么样"的成本，比年付划算。

## 谁适合 T1，谁不该省这笔钱

T1 适合的人：访问者在北美、欧洲或其他海外地区，或者你只是要一个能长期在线、流量大、不断网的节点。它的国际线路对国内用户不优化，晚高峰体验不能用"稳定"形容。

T1 不适合的人：站点或应用主要给中国大陆用户看。这种情况下省下来的钱会以另一种形式还回去——打开慢、跳失率高。该上 Pro 就上 Pro，电信用户对 CN2 GIA 的体感提升是实打实的；预算不够上香港 Pro，就先看洛杉矶 Pro 或者 EB，或者在 EB 和 Pro 之间按照自己的运营商选。

一个具体的换算：洛杉矶 Pro.TINY 月付 $9.99，香港 Pro.TINY 月付 $39.9，差价是四倍，但香港机房的国内延迟通常在几十毫秒以内，洛杉矶在 130–160ms 这个区间。要不要为这 100ms 付四倍的钱，取决于业务对延迟的敏感程度，而不是取决于哪台机器"更好"。

## 下单前的几个检查项

**先测再买。** DMIT 有公开的测试 IP：洛杉矶 Pro 是 154.17.30.96，洛杉矶 T1 出现过 174.136.204.135，香港 Pro 是 103.117.100.199，香港 T1 是 154.12.176.28，东京 T1 是 154.31.112.5。自己 ping 一遍、晚高峰再 ping 一遍，比看十篇测评都准。

**确认超量规则。** T1 系列明确是限速不停机。但不同产品线在这件事上不一样——东京 Pro 的说明是流量超出后会暂停。买之前在你选的那个套餐页上看清楚是"限速"还是"暂停"。

**确认库存和平台。** 同一款套餐可能挂在 AS3、AN4、AN5 不同批次上，价格和页面提示都不同。库存变动很快，看中的档位没货就是没货。

**付款方式。** 支持支付宝、PayPal 和信用卡，国内用户付款不算麻烦。

**IP 相关。** Pro 和 EB 系列在符合条件时可以申请免费更换被封的 IP，有周期限制，具体规则在官方的服务条款里，别照搬别人的经验。

**退款条款。** 不同产品线的退款政策不一样，付款前把 ToS 里那一节读完，比事后开工单省事。

## 常见问题

**$36.9/年这种价位，机器能用来干嘛？**
1 核 1GB、20GB SSD、4Gbps 端口，跑一个轻量 WordPress、静态站、Docker 小服务、定时任务、监控面板都够。跑不动的是高并发数据库和吃内存的 Java 应用。

**为什么同样是 1 核 1G，DMIT 比一些商家贵？**
贵的是线路和不超售。DMIT 的机器硬件是 AMD EPYC 系列 + NVMe SSD，路由里有自家的 AS906 骨干，多数超低价套餐给不到这些。如果你只看核心数和内存，市场上确实有更便宜的选择。

**买了发现线路不合适能退吗？**
看产品线的退款条款，以官方 ToS 为准。这也是建议重要业务先月付的原因。

**DMIT 会不会突然涨价？**
常规套餐是循环计价，标价续费同价。真正需要留意的是"补货特价"这类限量档位，卖完就没了，不太可能长期保持同样的价格。

**能不能用优惠码叠加？**
结算页会告诉你答案。循环折扣码和限时活动码的适用范围不一样，有的排除特定档位，硬凑没意义。
